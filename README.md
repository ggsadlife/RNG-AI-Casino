# AI Live Casino Lite

Open `index.html` in a modern browser. The demo works offline and does not require installation or a server.

The lobby banner composites a locally bundled transparent WebM dealer over a generated stage image. It starts muted and loops; click the speaker button to hear the original video's audio. A transparent still poster appears while loading. The WebM was keyed from the supplied blue-screen `dealer-welcome.mp4`. The remaining interface uses optimized crops of the screenshots supplied for this local project. Balance, roadmaps, dealers, and tables are illustrative data. The table pages are previews only; they do not accept bets or run games.

Optional: if Node.js is available, run `node smoke-test.js` to check the page flows without a browser.
