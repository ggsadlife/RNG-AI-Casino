# AI Live Casino Lite design context

- Purpose: offline, lightweight visual demo of the supplied AI Live Casino lobby.
- Visual source: user-provided screenshot. Preserve the 9:16 central frame, navy and electric blue chrome, purple hero, image-led game cards, and blurred side stage.
- Runtime: static HTML, CSS, and JavaScript. No external assets, fonts, services, or game engine.
- Interaction: browser hash identifies lobby, category, and table views. Visible table data and balance are local demo values. No betting controls.
- Accessibility: native buttons and selects, labeled imagery, keyboard focus, Escape-close dialogs, and reduced-motion support.
- Key colors: stage `#090e1c`, frame `#11162c`, header `#172a5a`, border `#579ce7`, cyan `#49d9ff`, text `#f4f8ff`.
